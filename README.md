# MediScan AI 🚀

MediScan AI is an AI-powered healthcare application designed to assist in medical diagnosis using advanced machine learning and TensorFlow Lite models. The application can analyze medical images, evaluate blood parameters, and provide AI-assisted healthcare guidance.

## ✨ Features

- 🦴 Fracture Detection
- 🧠 MRI Brain Analysis
- 🫁 CT Lung Scan Analysis
- 🩺 Pneumonia Detection
- 🩸 Blood Report Analysis
- 🤖 AI Medical Chatbot
- 💾 Save & Share Results
- 📱 User-Friendly Android Interface

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- TensorFlow Lite
- Machine Learning
- Material Design

1. Clone the repository

```bash

```

2. Open the project in Android Studio
3. Sync Gradle dependencies
4. Build and run the application
